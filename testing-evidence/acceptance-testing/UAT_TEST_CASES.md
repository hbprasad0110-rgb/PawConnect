# PawConnect User Acceptance Test Cases

## Purpose and usage

These cases are for human acceptance testing of the PawConnect adopter and administrator experiences. They are derived from the project proposal/progress documents, the repository requirements in [README.md](../../README.md), implemented routes/pages, and the existing automated test inventory.

## Test data and preconditions

- Application is running with the intended release candidate build.
- A dedicated UAT database is used; production data must not be used.
- Use a newly created adopter account for cases that create data.
- Use the configured administrator account for administrator cases.
- Use available animals and approved/pending applications created in the UAT database.
- Record screenshots, timestamps, account role, and any visible error text for every executed case.

## Status rules

- **PASS**: Human tester completed the steps and confirmed the expected result.
- **FAIL**: Human tester completed the steps and observed a deviation.
- **BLOCKED**: Execution could not proceed because of an environment, data, or access blocker.
